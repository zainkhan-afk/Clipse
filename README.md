# Clipse

A minimal cross-device clipboard sharing app. Copy on one device, paste on another —
text and images stay in sync.

- `backend/` — FastAPI + SQLAlchemy, cookie-based JWT auth.
- `frontend/` — Next.js (App Router), Tailwind v4, dark/light themes.

See `CLAUDE.md` for architecture and dev commands, and `run.sh` to start both together.
